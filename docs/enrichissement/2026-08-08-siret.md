## 1. Méthode

Source unique d'écriture : **`recherche-entreprises.api.gouv.fr`**. Aucune valeur n'a été écrite sur
la seule foi d'une recherche : chaque SIRET a été rappelé au registre puis confronté à la fiche CRM.

**Le juge exige deux concordances simultanées :**

1. **géographique** — même code postal *ou* même commune ;
2. **d'identité** — un jeton de nom significatif partagé (hors mots-métier : `climatisation`,
   `chauffage`, `énergie`, `SARL`…, et hors nom de la ville), *ou* la rue exacte quand le code NAF
   est bien celui du bâtiment.

Sont écartées d'emblée les entités qui ne peuvent pas être l'installateur : SCI, syndicats de
copropriété, associations, et tout NAF hors sujet (immobilier, santé, enseignement…).

**Quatre angles d'attaque**, parce qu'aucun ne suffit seul :

| | Requête | Ce que ça débloque |
|---|---|---|
| A | nom brut + code postal | le cas simple |
| B | nom nettoyé de sa queue SEO | `« MACHIN - Chauffagiste RGE Nantes »` → `MACHIN` |
| C | nom nettoyé + département | le siège est souvent dans la commune voisine |
| D | rue + commune | quand l'enseigne ne ressemble pas à la raison sociale |

Quand le registre ne rend pas la main — enseigne différente, entité non diffusible — la dernière
cartouche est le **site du client lui-même** : les mentions légales portent l'immatriculation, et le
lien « mentions légales » a été suivi depuis l'accueil plutôt que deviné.

## 2. Le piège qui a failli passer

Le premier juge confirmait des **copropriétés**. À une adresse parisienne dense, le
`SDC 12 AV LEDRU ROLLIN` partage la rue avec l'installateur cherché ; une concordance de rue ne
prouve donc rien toute seule. Sept fiches parisiennes (13, 14, 21, 22, 27, 29, 38) avaient reçu un
SIRET de syndic ou de SCI, et deux autres un SIRET de `BASIC-FIT FRANCE` (2052) et
d'`ASSOCIATION MURET SKATEBOARD` (2151).

Le juge a été durci — nom obligatoire, formes juridiques et NAF filtrés — et la passe relancée
intégralement. **Aucune de ces valeurs n'a été écrite en base.**

Un piège voisin a été attrapé au contrôle final : la fiche 2624 « SARL Carceller » pointait vers
`ASTRID CARCELLER`, NAF 96.09Z, à la même adresse — un autre commerce au domicile du gérant. La
bonne entité est `ENTREPRISE CARCELLER`, NAF 43.22B.

## 8. Outillage laissé en place

Les scripts de cette passe sont dans le scratchpad de session et non versionnés — ils sont
jetables, mais la logique mérite d'être reprise si l'hydratation par SIRET est industrialisée :

- `valide.py` — client `recherche-entreprises`, avec reprise sur 429/5xx et aplatissement
  siège + `matching_etablissements` ;
- `juge2.py` — le juge durci (formes juridiques interdites, familles NAF, jetons signifiants) ;
- `sites.py` — lecture des mentions légales en suivant le lien depuis l'accueil.
